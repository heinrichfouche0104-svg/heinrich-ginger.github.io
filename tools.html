Running the channels

ElevenLabs

Speech to text, and voiceover

Transcribes every shoot so the system can find the moments worth clipping. I've run hours of South African accents and mixed Afrikaans and English through it, which is where most transcription falls over.

Verdict: kept. The accuracy on accented, code-switched speech is the reason.

Claude

Picks the clips, writes the captions, and wrote the software

Reads the transcript of a shoot and chooses which moments will work as clips, then writes the posts. It also built the production system itself.

Verdict: kept. The whole operation is built on it.

upload-post

Posts to Instagram, TikTok, LinkedIn and X on a schedule

Holds the platform approvals so I don't have to apply for each one myself. YouTube I post to directly, because its own numbers are better.

Verdict: kept, on the cheapest plan that fits.
